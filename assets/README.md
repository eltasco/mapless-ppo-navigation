# Figures

`benchmark_success.png` illustrates **historical local evaluation results**
for the bundled checkpoint. Source numbers are in
[`results/recorded_benchmarks.csv`](../results/recorded_benchmarks.csv).
The image is not a new evaluation generated by CI.

`ppo_vs_potential.svg` compares the two controllers using the author-reported local benchmark from 11 November 2026 (500 episodes per obstacle count for each controller). The plotted success rates are descriptive in-distribution results; see [`results/paired_benchmark_summary.csv`](../results/paired_benchmark_summary.csv) for collision and timeout counts.
