# Visual assets

`benchmark_success.png` visualizes the recorded simulation success rates for the selected PPO policy across scenes with two to five obstacles. Source counts and conditions are documented in [`results/recorded_benchmarks.csv`](../results/recorded_benchmarks.csv) and [`docs/EXPERIMENTS.md`](../docs/EXPERIMENTS.md).

The figure summarizes historical evaluation results; it is not generated by the continuous-integration test suite.
