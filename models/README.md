# Model checkpoint

This repository includes one selected PPO policy:

```text
models/navigation_ppo.zip
```

The file is a Stable-Baselines3 checkpoint. **Do not unzip it.** To visualize or evaluate it:

```bash
python run.py view best hard 5
python run.py eval best hard 2-5
```

For architecture, SHA-256, environment versions and benchmark provenance, read [Model Card](../docs/MODEL_CARD.md). Other checkpoints generated by training are Git-ignored by default.

To load the checkpoint directly from Python:

```python
from stable_baselines3 import PPO

model = PPO.load("models/navigation_ppo.zip", device="cpu")
```
